# Agent Lobby — poczekalnia dla twoich agentów AI

Pracujesz z kilkoma sesjami Claude Code albo Codexa naraz i gubisz się, która na co czeka? Agent Lobby zbiera je w jednym pływającym panelu.

- **Wszystko na jednym widoku** — każdy agent ma własnego ludzika, nazwę, bieżący krok, postęp listy zadań i czas pracy.
- **Odpowiadasz bez przełączania okien** — „Zezwól”, „Odmów”, „Zawsze” albo wybór odpowiedzi na pytanie, prosto z panelu.
- **Wyspa przy wycięciu ekranu** — gdy agent skończy albo czegoś potrzebuje, z wycięcia na górze ekranu wysuwa się powiadomienie.
- **Szczegóły na kliknięcie** — lista zadań, ostatnie kroki, polecenie w terminalu i orientacyjny koszt rozmowy.
- **Dyskretny** — gdy nic się nie dzieje, panel zwija się do paska.
- **Prywatny** — nie wymaga logowania, nic nie wysyła do internetu. Czyta tylko pliki, które Claude i ChatGPT zapisują na twoim Macu.

Po polsku i po angielsku, aktualizuje się sam.

## Instalacja

1. Wejdź w [najnowsze wydanie](https://github.com/woreczko/agent-lobby/releases/latest) i pobierz plik **AgentLobby-….zip** (pozostałych nie potrzebujesz).
2. Rozpakuj go (Safari zwykle robi to samo).
3. **Przeciągnij „Agent Lobby” do folderu Programy** i uruchom stamtąd — inaczej aplikacja nie zaktualizuje się sama.
4. Przy pierwszym otwarciu potwierdź „Otwórz”, a potem „Włącz”, jeśli chcesz odpowiadać na prośby Claude Code prosto z panelu.

Panel pojawi się w prawym górnym rogu ekranu, a ikonka z ludzikami na pasku menu. W jej menu są język, wyspa, tryb dyskretny, uruchamianie przy logowaniu i sprawdzanie aktualizacji.

**Wymagania:** macOS 14 lub nowszy oraz [Claude Code](https://claude.com/claude-code) albo Codex w aplikacji ChatGPT.

# Agent Lobby — a waiting room for your AI agents

Running several Claude Code or Codex sessions at once and losing track of which one is waiting for you? Agent Lobby gathers them in one floating panel.

- **Everything at a glance** — every agent gets its own little character, name, current step, task-list progress and run time.
- **Answer without switching windows** — Allow, Deny, Always, or pick an answer to a question, right from the panel.
- **Notch island** — when an agent finishes or needs you, a notification slides out of the notch at the top of the screen.
- **Details on click** — task list, latest steps, the terminal command and an estimated cost of the conversation.
- **Discreet** — when nothing is happening, the panel shrinks to a slim bar.
- **Private** — no sign-in, nothing sent to the internet. It only reads files that Claude and ChatGPT already keep on your Mac.

In English and Polish, updates itself.

## Install

1. Open the [latest release](https://github.com/woreczko/agent-lobby/releases/latest) and download **AgentLobby-….zip** (you don't need the other files).
2. Unzip it (Safari usually does this for you).
3. **Drag “Agent Lobby” into your Applications folder** and open it from there — otherwise it can't update itself.
4. On first launch confirm “Open”, then “Turn On” if you want to answer Claude Code requests right from the panel.

The panel appears in the top-right corner of the screen, and an icon with little characters appears in the menu bar. Its menu has language, the notch island, discreet mode, launch at login and update checks.

**Requirements:** macOS 14 or later, plus [Claude Code](https://claude.com/claude-code) or Codex in the ChatGPT app.
